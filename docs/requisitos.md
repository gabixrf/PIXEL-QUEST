# Requisitos do PIXEL QUEST

## Objetivo
Desenvolver uma plataforma gamificada para ensinar lógica de programação de maneira interativa.

## Requisitos funcionais
- Cadastro de usuários.
- Login e autenticação.
- Exibição de aulas de lógica de programação.
- Realização de exercícios práticos.
- Missões e desafios.
- Sistema de pontuação e níveis.
- Conquistas e medalhas.
- Acompanhamento do progresso do aluno.
- Área administrativa para gerenciamento dos conteúdos.

## Requisitos não funcionais
- Interface simples e intuitiva.
- Segurança dos dados dos usuários.
- Armazenamento das informações em banco de dados MySQL.
- Validação dos dados enviados pelos usuários.
- Compatibilidade com navegadores modernos.
